# Mini curso SBPC 2025 - ONCOGENÔMICA: FUNDAMENTOS, AVANÇOS E DESAFIOS NA PESQUISA DO CÂNCER
Arquivos para o treinamento ONCOGENÔMICA: FUNDAMENTOS, AVANÇOS E DESAFIOS NA PESQUISA DO CÂNCER. São 3 arquivos notebook Jupyter referente aos dias de prática do curso, sendo o primeiro dia de aula teórica. 
Cada aluno precisa ter uma conta do Google para uso do Google Colab. Os arquivos devem ser baixados e adicionados ao google drive do aluno para em seguida ser usado no Google Colab.
